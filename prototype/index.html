Register a process

Register one process directly or apply a process manifest.

port-start process register \
  --label "Storefront web" \
  --kind service \
  --tag project:storefront \
  --tag frontend \
  --port http=http://127.0.0.1:4310/ \
  -- npm run dev -- --port 4310

Deregister process

This removes the process from the current inventory.

Retained run logs stay available until their retention limit expires.
